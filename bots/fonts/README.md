# Шрифты для мамонтов

## Как добавить шрифт

1. Скачайте файл шрифта в формате `.ttf` или `.otf`
2. Поместите файл в эту папку `bots/fonts/`
3. Система автоматически будет использовать первый найденный шрифт

## Поддерживаемые форматы
- `.ttf` (TrueType Font)
- `.otf` (OpenType Font)

## Примеры шрифтов
- `arial.ttf`
- `calibri.ttf`
- `roboto.ttf`
- `opensans.ttf`

## Настройки текста
- **Размер**: 72px
- **Позиция**: 790x110 (с автоматической корректировкой если не помещается)
- **Цвет**: Белый с черной обводкой
- **Обводка**: 3px для лучшей читаемости

## Fallback
Если шрифты в папке не найдены, система использует системные шрифты:
- Windows: Arial, Calibri, Tahoma
- Linux/Mac: DejaVu Sans Bold, Liberation Sans Bold, Arial
